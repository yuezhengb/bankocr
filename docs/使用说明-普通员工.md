# BankOCR 桌面版使用说明

面向 Windows 离线包用户（双击 `bankocr-gui.exe`，无需命令行）。

## 开始使用

1. 打开收到的 BankOCR 文件夹，**双击 `bankocr-gui.exe`**。
2. 在窗口中选择需要处理的 PDF，也可以把 PDF 文件直接拖入窗口。
3. 确认文件列表后，点击**开始处理**。
4. 处理完成后，点击**打开输出文件夹**。

## 查看处理结果

输出文件位于：**文档\BankOCR\输出**。

在输出文件夹中，您可以：

- 打开 Excel 文件查看识别出的交易流水；
- 打开 **PDF 原样 Excel**，每个工作表对应 PDF 的一页，用来和原始页面视觉对照；
- 打开可搜索 PDF，在 PDF 中搜索文字；
- 打开核对版 PDF，把 Excel 里的 `comparison_id`（例如 `T0001`）与 PDF 页面上的同编号框对应起来；
- 对需要确认的内容，点击界面中的**开始人工复核**，按提示检查和确认。

### 怎么核对

1. 需要搜索、统计时，打开普通 `.xlsx` 的 `Transactions` 表；
2. 需要看原始排版时，打开 `*.pdf-layout.xlsx`，在“核对索引”中按 `comparison_id` 点击页码链接；
3. 需要看错误框和颜色时，打开**核对版 PDF**，找到同一个编号；
4. 对照原始页面检查日期、金额、余额、对方账号和摘要；
5. 黄色或红色记录优先处理；没有框的记录请打开普通 Excel 的 `Source Index` 查看来源信息。

普通 `.xlsx` 和 `pdf-layout.xlsx` 不是重复文件：前者能筛选统计，后者保留 PDF 的原始视觉排版，图片里的文字不能直接作为 Excel 单元格筛选。

颜色含义：绿色为已确认且校验通过，黄色为待复核，红色为关键问题，灰色为重复或拒绝记录。

## 复制或迁移

如需把 BankOCR 交给另一台电脑使用，请**复制整个 BankOCR 文件夹**。不要只复制 `bankocr-gui.exe`；同级的 `models`、`templates` 和 `fonts` 文件夹也必须一并保留。

处理过程中不会修改原始 PDF。原始文件会保持不变，结果会另存到输出文件夹。
