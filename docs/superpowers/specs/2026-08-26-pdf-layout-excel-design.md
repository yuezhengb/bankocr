# PDF 原样图片版 Excel 设计

## 目标

在现有普通结构化 Excel、人工复核 Excel、可搜索 PDF 和核对版 PDF 之外，增加一份可直接与原始 PDF 视觉对照的 `pdf-layout.xlsx`。这份文件不替代结构化 Excel，而是把原 PDF 每一页作为图片放入一个独立工作表，并通过“核对索引”把流水记录映射到页码、行号和 `comparison_id`。

## 方案选择

候选方案有三种：

1. **用 Excel 单元格重画 PDF 表格**：可筛选，但不同银行的字体、合并单元格、分页和坐标差异会造成明显偏移，不能保证原样。
2. **把 PDF 页作为图片放进 Excel**：视觉上最接近原文，能保留原始字体、线条、印章和分页；代价是图片版不能像普通 Excel 一样筛选和编辑。
3. **只提供可搜索 PDF**：视觉最稳，但不满足用户希望在 Excel 文件里逐页查看和归档的需求。

本项目采用方案 2，同时保留方案 1 已有的结构化 Excel。两份文件职责明确：

- `<文件名>.xlsx`：搜索、统计、筛选、后续整理。
- `<文件名>.pdf-layout.xlsx`：逐页视觉对照，不能当作结构化表格使用。

## 输出结构

`<文件名>.pdf-layout.xlsx` 包含：

- `核对索引`：第一行说明用途；后续记录每个交易的 `comparison_id`、页码、行号、状态、最终值、源位置状态和跳转链接。每条记录可点击链接跳到对应的 `第001页` 工作表。
- `第001页`、`第002页`……：每个 PDF 页面一个工作表，插入原 PDF 页面渲染图，不叠加 OCR 字符、不改变原文内容。页面比例按 PDF 原始宽高设置，工作表按横向打印、适合一页宽度配置。

索引只用于定位，不声称图片中的每个视觉字符已经被 Excel 单元格识别。真正可统计的字段仍以普通 `.xlsx` 的 `Transactions` 页为准；人工复核时优先打开原 PDF 或 `comparison.pdf`，图片版 Excel 用于在一个 Excel 文件中快速翻页对照。

## 图片和资源约束

- 默认按 150 DPI 渲染页面，避免在普通 4 核 4 GB 机器上生成不必要的大文件；原 PDF 不被修改。
- 图片使用 PNG，避免 JPEG 压缩把小数点、负号和中文笔画压糊。
- 每页图片先写入临时目录，再由 `openpyxl` 嵌入工作簿；导出结束后清理临时文件。
- 空白 PDF 页面也必须生成对应工作表，保证页码不变。
- PDF 页数和图片渲染失败必须让导出失败并记录异常，不能生成“看起来成功但少页”的文件。

## 接入点

- 新增 `bankocr.export.pdf_layout.PdfLayoutExcelExporter`。
- `PdfTaskExecutor` 和 CLI 都调用同一个导出器，避免桌面端和命令行输出不一致。
- `ExportManifest.outputs`、summary JSON 和 GUI artifact 映射增加 `pdf_layout_excel`。
- 桌面端新增“打开 PDF 原样 Excel”按钮；原有“打开 Excel”继续打开普通结构化 Excel。

## 验收标准

1. 给定一个 N 页 PDF，生成的 `pdf-layout.xlsx` 能被 `openpyxl` 打开，并且恰好有 `N + 1` 个工作表：一个索引页和 N 个页面页。
2. 页面页名称按 `第001页`、`第002页` 顺序生成，图片数量与 PDF 页数一致。
3. 页面图片的宽高比与对应 PDF 页面宽高比一致，且图片中不包含 OCR 覆盖层或核对标记。
4. 索引含有每个候选交易的 `comparison_id` 和 PDF 页码，并带有指向正确页面工作表的超链接。
5. 普通 `.xlsx`、`.review.xlsx`、`.searchable.pdf`、`.comparison.pdf` 的内容和名称不被破坏。
6. CLI 和桌面任务队列都把新文件列入输出摘要、导出清单和可打开的结果按钮。
7. 原 PDF SHA-256 不变；新文件导出失败时不会伪造完成状态。

## 已知边界

图片版 Excel 的目标是“原样视觉对照”，不是把 PDF 变成可编辑的 Excel 表格，也不保证在 Excel 中可以对图片内的文字搜索、筛选或复制。需要搜索、统计时使用普通 `.xlsx`；需要核对原字形、位置和分页时使用图片版或原 PDF。
